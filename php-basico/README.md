# PHP Básico

Repositório criado para armazenar as atividades práticas desenvolvidas durante os estudos de PHP.

## Tecnologias utilizadas

- PHP
- HTML5
- Laragon
- Git e GitHub
- Visual Studio Code

## Atividades desenvolvidas

### 01 - Hello World
Exibição de mensagens na página utilizando PHP, variáveis e `echo`.

### 02 - Data e Hora
Exibição da data e hora atual, com saudação de acordo com o horário.

### 03 - Calculadora de IMC
Cálculo do Índice de Massa Corporal (IMC), classificação e validação de peso e altura.

### 04 - Produtos
Cadastro de produtos utilizando arrays, exibição em tabela HTML, cálculo do valor total do estoque e formatação de preços com funções.

## Como executar o projeto

1. Instale e abra o Laragon.
2. Inicie o Apache.
3. Coloque o projeto na pasta `www` do Laragon.
4. Abra o navegador e acesse:

`http://localhost/01-hello-world/`

Para acessar as outras atividades, substitua o nome da pasta na URL.

## Objetivo

Praticar os conceitos básicos da linguagem PHP, desenvolvendo atividades que envolvem variáveis, estruturas condicionais, laços de repetição, arrays e funções.
